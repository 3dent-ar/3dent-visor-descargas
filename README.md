# 3DENT Visor — Descargas

Programa para Windows que abre escaneos intraorales (STL y PLY, con su color) y tomografías (DICOM de CBCT).

## Instalar
1. Entrá en **[Releases](../../releases/latest)** y bajá el archivo terminado en `-setup.exe`.
2. Abrilo. Si Windows muestra «Windows protegió su PC», tocá «Más información» → «Ejecutar de todas formas».

Si ya lo tenés instalado, las versiones nuevas se descargan solas y el programa avisa cuando están listas para instalar.

También se puede usar desde el navegador, sin instalar nada: **https://visor.3dent.ar**
